Install on Android

  1. Tap Download CMZ app (APK). Wait for the APK download to finish.
  2. Open the downloaded APK and review Android’s install prompt.
  3. If Android asks, allow your browser to install apps from this source, then return to the APK and continue.
  4. After installation, you can turn that browser permission off again in Android Settings.
Android may warn that the app was downloaded outside Google Play. Check that you downloaded it from the official Creative Math Zone website. Do not install APK files forwarded from other sources.

To update later, download the new version from this page and install it over the existing app.

Use the Android web app instead

You can use the portal without downloading the APK. Open this website in Chrome, open the menu, and choose Install app or Add to Home screen.

On iPhone or iPad

There is no APK for iPhone or iPad. Open this website in Safari, tap Share, then Add to Home Screen.
